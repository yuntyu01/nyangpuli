# 사주·일운 비교 어댑터

Go가 요청 검증·비교 조건·프롬프트를 조립하고, 실제 만세력 계산은 고정한 OhMySaju Node 엔진으로 수행한다. 완전한 Go 이식은 아니다.
한 번 계산한 동일 원국에 YueYuan 조후표만 추가한 조건을 비교한다. 선택한 해석 자료는 아직 고전 원문 전수 대조·한국어 전문가 검수를 거치지 않았다.
일운은 실제 일진·십신·원국과의 관계 데이터이며, 운세 점수나 사건 예측을 생성하지 않는다.
기본 실행 결과는 근거와 프롬프트다. LLM 답변 품질이나 실제 적중률 시험이 아니다.

## 실행

필요: Node 20 이상, Git, pnpm 10.15.0. 저장소 루트에서:

```sh
bash scripts/setup-saju.sh
SAJU_INTEGRATION=1 go test ./internal/saju -v
```

`setup-saju.sh`는 `.upstream/oh-my-saju`에 고정 커밋을 받으며, 원본의 lockfile로 의존성을 설치하고 빌드한다. 재실행 시 변경된 tracked 파일을 덮어쓰지 않는다. `.upstream`은 Git에 올리지 않는다. 빌드에는 원본 배포 도구의 네트워크 접근이 필요할 수 있다. 다른 설치 위치를 사용할 경우 서버 환경변수 `OHMYSAJU_DIR`로 설정한다. 요청 JSON으로 실행 경로나 명령어를 받지 않는다.

```json
{
  "case_id": "saju-calendar-001",
  "question": "연락을 다시 시작하기 전에 무엇을 확인할까?",
  "birth": {"year": 1992, "month": 10, "day": 24, "hour": 5, "minute": 30, "time_zone": "Asia/Seoul"},
  "date": {"year": 2026, "month": 6, "day": 28}
}
```

이 생년월일은 엔진 회귀 fixture에서 가져온 시험 입력이다. 실제 앱 사용자 기록이 아니다. `date`는 생략 가능하다.

## 구현된 범위

| 조건 | 입력 및 계산 | 해석 근거 |
|---|---|---|
| `ohmysaju_only` | OhMySaju 원국 1회, 선택 날짜의 일운 | 원국 및 일운 JSON |
| `ohmysaju_plus_yueyuan_tiaohou` | 위와 완전히 같은 원국/일운 | 위 데이터 + 일간·**계산된 월지**로 찾은 조후표 1행 |

두 조건은 질문, 원국, 일운, 공통 지시문을 공유한다. 월지는 절기 경계를 반영한 엔진 출력에서 얻고 숫자 생월로 대체하지 않는다. 추가 조건에도 미래 사건의 사실 여부를 알 수 있는 새로운 관측 정보가 들어오는 것은 아니다.

YueYuan에서 가져온 것은 `TIAO_HOU` 120칸과 원문 주석, 조회 방식뿐이다. 신강약·격국·대운·궁합 해석 함수를 이식했다고 주장하지 않는다. 원저자가 표의 전수 원문 대조가 없다고 명시했으므로 모든 조회 결과에 `experimental_unverified_source_table`을 붙인다.

일운은 출생 IANA 시간대의 해당 날짜 **민간시계 정오 12:00**를 대표 시점으로 계산한다. 연·월·일주, 일간 대비 십신, 원국 네 기둥과 일진 사이 원시 합충형파해 관계를 돌려준다. 하루 전체에 동일한 월주가 유지된다는 보장이나 행운/연애 점수는 없다.

현재 어댑터는 양력 1801~2100, 정확한 출생 시·분, IANA 시간대, 민간시계, 자정 일주 교체만 지원한다. 시간 미상은 오류로 처리하고 정오로 채우지 않는다. 음력 변환·진태양시·시간미상 가능성 계산은 원본 엔진에 기능이 있어도 이 어댑터에 아직 노출하지 않았다.

## 검사 해석

자동 검사는 입력 검증, 시간미상 거부, 120개 조회 누락·메모·천간 유효성, 잘못된 키의 거부, 의존성이 없을 때 가짜 원국을 만들지 않는지 확인한다. 통합 검사는 실제 엔진의 1992-10-24 네 기둥, 2024년 입춘 양쪽 날짜, 2026-06-28 정오 일진, 잘못된 시간대 거부 및 두 조건의 원국 동일성을 확인한다. 기대값 일부는 원본 회귀 fixture를 가져왔으므로 독립적인 천문 검증으로 계산하지 않는다.

테스트 통과는 데이터 연결·회귀 동작의 근거다. 사주 해석 품질, 연애 상담 효과, 미래 연애 사건 적중률이 올라갔다는 근거는 아니다. 별도 고정 모델 A/B 평가와 실제 결과 사전 등록 추적이 필요하다.

## 실행 자원과 입력 제한

Go 어댑터는 프로세스 전체에서 Node 동시 실행을 최대 4개로 제한하고, 슬롯 대기와 실행에 합쳐 15초 제한을 적용한다. 요청 취소는 슬롯 대기와 프로세스에 전달된다. 사용자 입력은 실행 파일 또는 스크립트 경로를 지정하지 않으며 IANA 시간대를 검증한다. 시간 미상과 음력은 이 어댑터에서 지원하지 않고 오류를 반환한다. 한국천문연구원 실제 API와 원시 공식 응답 fixture를 통한 독립 대조는 아직 검증되지 않았다. 제3자가 수집한 KASI 유래 자료 대조 결과와 한계는 `docs/kasi-validation.md`에 기록했다. 원본 엔진 회귀 일치는 공식 자료와의 일치를 의미하지 않는다.
