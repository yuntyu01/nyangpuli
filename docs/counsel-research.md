# 상담 조사 자료와 비교 평가

`dugyeol_youtube_review.xlsx`의 2026-10-08 기록을 사용했다. `선별 결과`는 32개 영상과 댓글 표본 361개이며, 자막·댓글 대조 31개와 댓글만 확인한 1개를 구분한다. 공개 자막과 표시된 댓글을 대조했으며 영상 전체를 재생한 조사는 아니다. `전체 목록`은 일반 영상 605개, Shorts 2887개이며 목록 포함 자체는 본문 검토가 아니다. 댓글은 자기선택 표본으로 좋아요·공감은 조언 효과나 재회 성공률이 아니다.

`두결 조언 카드`는 원문을 복제하지 않고 다시 쓴 편집 초안으로 효과가 검증된 상담 처방이 아니다. 원영상 권리 검토는 완료되지 않았다. 세 우선 주제의 카드만 `internal/counsel/research_cards.json`에 구조화했다. 카드마다 상황, 공감, 해석, 질문, 행동, 예외, 상태, 원영상 URL·시간대, 원영상에서 참고한 부분, 자체 편집 부분과 버전을 함께 둔다. 보류·제외 주장은 검색 후보가 아니다. 나머지 전체 목록을 임베딩하거나 조언으로 취급하지 않는다.

현재 세 카드는 조건부다. 출처가 있는 구조화 사실로 안전, 상호 대화 의사, 연락 허용이 모두 확인될 때만 후보가 된다. 알 수 없거나 충돌하면 후보에서 제외하고 질문부터 한다. 이 보수적 규칙은 안전 판정이나 인간 검토를 대체하지 못한다. 개인 기억은 공통 카드와 별도로 유지해야 하며 명시적인 최신 경계를 우선해야 한다. 모델 요청은 카드를 지시가 아닌 자료로 전달하고 카드 ID와 버전을 `Sources`에 남긴다. 스냅샷은 실제 생성 결과와 같은 요청을 가리키도록 보관해야 한다.

## 평가

`fixtures/counsel-research-evaluation.json`은 같은 합성 상황을 자료 미사용과 자료 사용 양쪽에 제공하는 평가 입력과 평가 항목이다. `lab.ResearchComparison`은 각 사례에서 확인 사실을 동일하게 유지하고 기존 `enhanced` 조건에 대해 `include_research: false`와 `true` 입력을 구성한다. 생성 입력만 준비하며 모델을 호출하지 않는다. 결과는 기존 `generation.Run`과 `evaluation.Export`에 전달할 수 있다. 기존 baseline과 enhanced를 비교하면 BCcampus 자료도 함께 달라지므로 조사 카드 효과만 분리할 수 없다. 실제 모델의 답이나 품질 점수가 아니다. 공감, 상황 적합성, 구체적 행동, 근거 없는 단정, 예외 준수, 반복 표현을 사람이 각각 평가해야 한다. 비용·모델 설정이 없으므로 실모델 평가는 미실행이다. 가상 사례, 자기평가나 댓글 반응으로 미래 적중률을 산출하지 않는다.

영상 `_aDIzBDUXGY`는 평가용 출처 그룹으로 예약해 검색에서 제외한다. 같은 원본·모음집·재편집 및 파생 카드·댓글이 있다면 같은 그룹에 추가해야 한다. 이 문서는 전체 영상 간 중복 관계를 검증했다는 뜻이 아니며, 추가 자료를 넣기 전에 그룹 관계와 사용 권한을 검토해야 한다. 현재 입력의 합성 사례는 해당 영상의 내용·댓글을 사용하지 않는다. 독립적인 실제 평가 세트 구축과 원영상 권리 검토는 남아 있다.

모바일 상담 화면은 위협·보복 우려, 상대의 대화 의사와 연락 허용 여부를 각각 선택적으로 묻는다. 답하지 않거나 모르는 항목을 확인된 사실로 만들지 않는다. 선택한 답에는 해당 요청의 출처 식별자와 확인 시각을 넣으며, 자동으로 장기 기억에 저장하지 않는다. 사용자가 저장한 기억 사용을 허용했다면 저장된 경계도 함께 확인한다. 상충하거나 해석할 수 없는 경계는 허용으로 추정하지 않으며 카드 대신 먼저 확인한다. 현재 구현은 상충 정보의 시각만으로 허용을 판단하지 않는 보수적인 정책이므로, 기존 경계가 바뀌었다면 기억 관리에서 수정해야 할 수 있다. 이는 코드 경로와 조건을 검증한 것이며 실제 모델 답변이나 상담 효과는 평가하지 않았다.
