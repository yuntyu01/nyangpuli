# KASI 자료 대조와 실시간 API 상태

`node scripts/kasi-comparison.mjs`는 `bash scripts/setup-saju.sh`로 빌드한 고정 OhMySaju 원본과 저장된 자료를 비교한다. 자료는 OhMySaju 고정 커밋의 `test/fixtures/kasi-lunar-dataset.json`에서 복사한 200행이다. 원본의 출처 문서는 data.go.kr의 `getLunCalInfo` 자료를 제3자 `jinill1/korean-lunar-calendar`의 revision `6f988e3f50a424d165b9834f9e28cd3ea962da63`에서 수집했다고 기록하며, 원본 import 날짜는 2026-07-26이다. 조회별 실제 요청 조건과 수집일은 제공되지 않았다. 원시 공식 응답이 아니므로 공식 API를 직접 조회한 결과로 취급하지 않는다. 수집 자료의 SHA-256과 MIT 고지는 `fixtures/kasi/`에 보관한다.

비교는 원본 테스트의 두 역사적 역법 차이(1637-06-13, 1643-03-13)를 명시적으로 제외하고 나머지 198행의 양·음력 양방향 및 윤달 여부를 확인한다. 엔진 지원 출생연도 1801~2100의 115행은 현지 정오 일주와 수집된 일진을 비교한다. 2건을 일치로 세지 않는다. 음력 연·월 간지를 절기 기준 연주·월주와 동일하게 보지 않으며 이 비교는 절기 경계의 공식 정밀도나 미래 사건을 평가하지 않는다.

`internal/kasi`는 설정한 `https://apis.data.go.kr` 경로에만 HTTPS 요청을 보내는 제한된 원시 응답 수신 구성요소다. 키는 코드나 로그에 기록하지 않고 타임아웃과 응답 크기 제한, 리다이렉트 차단을 적용한다. 테스트 응답은 합성 데이터이며 공식 응답 fixture가 아니다. HTTP 200만으로 API의 업무 성공을 판단하지 않는다. 현재 공식 문서가 환경 네트워크 정책으로 차단되어 정확한 엔드포인트, 인증 파라미터, 요청·응답 스키마를 확인하지 못했고, 실제 API 키와 공식 원시 응답을 사용한 테스트도 수행하지 않았다. 따라서 이 구성요소는 자동으로 켜지거나 앱의 계산 근거로 사용되지 않는다. 문서 접근과 인증이 가능해지면 공식 스키마 및 오류 코드를 확인하고 조회 조건·조회일·출처를 기록한 원시 응답 fixture를 확보한 뒤 파서 및 실시간 호출을 검증해야 한다. API 값은 채팅이나 Git에 저장하지 않는다.
