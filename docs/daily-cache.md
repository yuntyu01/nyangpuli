# 일운 캐시 기반

`internal/daily.LocalDate`는 서버 호스트 시간이 아닌 명시한 IANA 시간대의 날짜를 계산한다. PostgreSQL 캐시 키는 인증된 계정, 해당 계정 소유 프로필 ID와 버전, 현지 날짜와 시간대, 엔진·자료·프롬프트·모델 버전을 모두 포함한다. 사용자나 프로필을 바꾸거나 어느 버전이 바뀌면 다른 캐시 항목이다. 저장은 현재 프로필 소유권과 버전을 SQL에서 확인하고 동일 키에는 최초 저장값만 유지한다. 생성 호출은 트랜잭션 밖에서 수행하므로 동시 생성 비용까지 방지하지는 않는다.

프로필 버전이 변경되면 예전 값은 조회되지 않으며 계정 삭제의 프로필 삭제에서 캐시도 함께 제거된다. 삭제 후 새 값 저장은 허용하지 않는다. 이 구성요소는 아직 프로필/일운 API 및 모바일 홈에 연결되지 않았다. 연결 시 계정은 검증된 인증에서, 프로필·버전·시간대는 서버 조회에서 가져와야 한다. 키에 클라이언트가 제출한 계정 또는 버전 값을 신뢰해서는 안 된다. 읽기·생성 중 중복 과금 방지는 별도 생성 작업의 멱등성 제어가 필요하다. 현지 날짜 및 캐시 기반만으로 일운 답변이 생성되거나 실제 모델이 검증된 것은 아니다.
