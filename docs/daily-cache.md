# 프로필과 일운

PostgreSQL 사용 시 인증된 계정은 `POST /v1/profiles`로 양력 출생 정보 `{ "birth": { "year": 1990, "month": 1, "day": 1, "hour": 12, "minute": 0, "time_zone": "Asia/Seoul" } }`를 저장하고, `GET /v1/profiles`로 자신의 프로필 목록을, `GET /v1/profiles/{id}`로 단건을 조회한다. `PUT /v1/profiles/{id}`는 `{ "version": 1, "birth": { ... } }`를 받고 버전이 맞을 때만 수정한다. 다른 계정의 프로필에 접근할 수 없다. 음력 출생은 `calendar: "korean-lunar"`과 `month_kind: "regular"` 또는 `"leap"`을 추가한다. 프로필 저장·수정 시 실제 음력 날짜·윤달 존재 여부를 고정 원본 엔진으로 확인하고 엔진을 사용할 수 없으면 저장을 거부한다. 시간 미상은 임의 시간으로 치환하지 않고 거부한다.

`POST /v1/daily`는 `{ "profile_id": "...", "time_zone": "Asia/Seoul" }`을 받는다. `time_zone`은 현재 사용자의 IANA 시간대이며 필수다. 현지 날짜는 서버 시각이 아닌 이 시간대로 계산한다. 출생 계산에는 프로필의 출생 시간대를 사용한다. 현재 시간대가 출생 시간대와 같으면 고정 원본의 일운 API를 사용한다. 두 시간대가 다르면 출생 정보로 원국을 계산하고 현재 시간대의 현지 정오를 별도로 원본 `calculateSaju`에 전달해 일진을 계산한다. 이 별도 경로에서는 원본 일운 API의 원국 관계와 십성을 계산하지 않고 `null`로 표시하며, 서로 다른 시간대에서 계산되지 않은 관계를 모델이 사실로 주장하지 않도록 제한한다. 원본 엔진의 독립 호출 결과를 조립한 방식이며 원본 일운 API를 그대로 호출한 결과는 아니다.

캐시 키에는 인증된 계정, 서버에서 확인한 프로필 ID와 버전, 현지 날짜와 시간대, 엔진·자료·프롬프트·모델 설정 버전을 포함한다. 동일 키는 기존 생성 작업을 재사용하고 중복 요청은 진행 중 상태를 반환한다. 프로필 변경은 새 키를 사용하며 계정 삭제 시 프로필과 캐시도 삭제된다. 결과 캐시에는 무료 요약만 저장·반환한다. 상세는 별도 열람 API에서 현재 권한을 확인해야 하며, 캐시 재생성이나 권한 회수 후에도 상세를 반환하지 않는다. 구버전 캐시의 상세 필드는 011 마이그레이션으로 제거하고 재삽입을 제한한다.

모델이 설정되지 않으면 새로운 일운 생성은 503이다. 실제 모델의 응답 품질이나 스토어 구매는 이 API 테스트로 검증되지 않았다. 현재 일운 생성은 동기 요청이며 진행 상태를 재조회하는 별도 일운 화면 연동은 미완료다.
