# 구매 검증 계약의 현재 상태

`internal/purchase`는 서버 검증 어댑터와 원자적 저장소 경계만 정의합니다. 검증 결과는 스토어가 확인한 계정, 상품, 거래 ID 및 현재 상태여야 하며 클라이언트의 성공 표시는 권한의 근거가 아닙니다. 어댑터나 저장소가 없으면 실패합니다. 저장소는 한 거래를 한 사용자와 한 풀이에만 연결하고, 중복 알림을 멱등 처리하며, 환불 뒤 오래된 알림으로 권한이 되살아나지 않게 버전 순서를 보장해야 합니다.

현재 계약 시험에는 모의 검증기와 메모리 저장소만 사용합니다. Apple/Google의 실제 영수증 검증, 신뢰 가능한 상태 순서의 확보, PostgreSQL 저장소와 API/모바일 연결은 구현되지 않았습니다. 실제 스토어의 데이터로 안전한 순서를 제공할 수 있다는 점을 검증하기 전에는 이 계약으로 운영 구매를 처리하지 마세요. 개발용 해제는 구매가 아닙니다.
