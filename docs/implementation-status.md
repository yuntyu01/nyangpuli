# 구현 현황

2026-10-29 작업 기록. 각 단계는 별도의 구현·검증이 모두 끝난 경우에만 완료로 표시한다. 현재 제품은 운영 배포용이 아니다.

## 1. 기존 코드와 실행 기반 — 진행 중

첨부 ZIP을 초기 커밋으로 보존했다. 기존 Go 연구 API에는 OhMySaju TypeScript 어댑터, 사주·타로 조립, JSON 기억과 풀이, 모델 클라이언트, 요약·상세 잠금 및 보관함 실험이 있었다. 운영 계정, PostgreSQL 기반 전체 저장, 모바일 앱과 스토어 결제는 없었다. `NOTICE.md`, `sources.lock.json` 및 외부 자료를 보존했다. Git 고정 커밋의 OhMySaju Apache-2.0 LICENSE·NOTICE, YueYuan·Tarotoo·Arcanite MIT LICENSE, Mem0 Apache-2.0 LICENSE를 확인했다. BCcampus 이용 조건은 별도 문서 참조.

기준 `8a2958f`에서 Go 1.27.3 `go test ./...` 통과. 고정 OhMySaju 설치·빌드 및 Compose 기동을 확인했다. 설치·시작 방법은 `docs/local-environment.md`와 모바일 README를 참조한다.

## 2. PostgreSQL과 사용자 — 진행 중

마이그레이션, 사용자별 해시 세션, 개인 기억, 생성 예약 및 삭제 기반을 추가했다. 실제 PostgreSQL에서 마이그레이션 동시 적용, 세션·기억 격리, 늦게 저장된 과거 기억, 동시 예약, 삭제 후 쓰기 방지를 시험했다. 계정 발급·복구, JSON dry-run 이관, 풀이와 구매의 DB 전환은 미완료다. 현재 Compose API는 기본 JSON 랩 저장소를 사용한다. 운영 모드는 차단된다. `docs/postgresql.md` 참조.

## 3. 사주·운세·궁합 — 진행 중

원본 Node 엔진을 유지하며 시간대 검증과 실행 제한·취소를 추가했다. 기존 원본 통합 Go 테스트는 통과했다. 고정 원본 회귀 스크립트는 빌드 트리 해시가 golden과 달라 실패한다. 진단용 출력 비교는 20/20 일치했지만 provenance 검사 우회 결과이므로 원본 회귀 통과가 아니다. Node 버전을 맞춰도 해시 차이가 재현되었다. 공식 자료 대조로 upstream에 보관된 제3자 수집 KASI fixture의 변환·일진 시험 3개는 통과했으나 원시 공식 응답·실시간 API는 미검증이다. 음력·출생시간 미상 입력, 일운 저장 캐시 및 공식 API 연동은 미완료다.

## 4. 타로 — 진행 중

기존 78장 의미와 배치를 유지하고 서버용 무작위·중복 없는 선택, 방향 고정과 세션 직렬화 기반을 추가했다. 관련 Go 시험 통과. HTTP·DB 연결, 상세 구매 및 모바일 선택 흐름은 미완료다. 카드 이미지 이용 조건은 별도로 확인해야 한다.

## 5. 개인 기억·공통 지식 — 진행 중

개인 기억과 공통 상담 자료를 분리했다. 첨부 엑셀의 2026-10-08 기록에서 선별 32개(자막·댓글 31, 댓글만 1), 댓글 표본 361개와 전체 목록 일반 605개·Shorts 2887개를 구분했다. 전체 목록의 본문 검토나 댓글 반응의 효과 검증을 주장하지 않는다. 세 우선 주제의 조건부 카드에는 출처, 시각, 행동과 예외, 버전을 함께 저장하고 안전·상호 의사·연락 허용이 확인되지 않으면 선택하지 않는다. 보류·제외 및 평가 그룹은 후보에서 제외한다. 검색 선택과 입력 비교 테스트 통과. 원영상 권리, 동일·재편집 출처의 전체 그룹 관계, 추가 자료의 독립 평가 세트는 미검토다. 자세한 출처와 제한은 `docs/counsel-research.md` 참조.

## 6. 생성·무료 요약과 상세 — 진행 중

기존 모델 어댑터와 같은 근거 스냅샷을 유지하고 호출 결과가 불확실한 작업의 자동 재호출을 차단했다. 모델과 프롬프트 해시, 상담 카드 ID·버전을 생성 입력에 기록한다. 관련 단위 시험 통과. DB 작업 예약은 기존 생성 서비스에 미연결이며 전역 JSON 잠금이 남아 있다. 실제 모델 답변과 사용량·품질은 평가하지 않았다.
