# 구현 현황

이 문서는 단계별 실제 구현과 검증을 기록합니다. 완료하지 않은 항목을 완료로 간주하지 않습니다.

## 1. 기존 코드와 실행 기반 — 진행 중

첨부 ZIP을 초기 커밋으로 가져왔다. 기존 Go 연구 API에는 OhMySaju TypeScript 어댑터, 사주·타로 조립, JSON 기억과 풀이, 모델 클라이언트, 무료 요약·상세 잠금 및 보관함 실험이 있다. 운영 계정, PostgreSQL 기반 저장, 모바일 앱과 스토어 결제는 기존에 없었다. 원본 출처와 라이선스는 `NOTICE.md`와 `sources.lock.json`에 보존했다.

기준 커밋 `8a2958f`의 `go test ./...`는 Go 1.27.3에서 통과했다. 기존 기록의 결과는 과거 검증이며 이번 실행과 구분한다. 원본 엔진 설치 및 회귀 검증과 고정 원본 라이선스 확인은 진행 중이다.

## 2–10. 진행 중

PostgreSQL, 사주·타로, 상담 자료, 앱, 결제와 개인정보 삭제, 통합 검증은 구현과 검증을 진행 중이다. 실제 외부 서비스의 자격 증명이나 스토어 설정은 현재 확인되지 않았으며, 실연동을 검증한 것으로 취급하지 않는다.
