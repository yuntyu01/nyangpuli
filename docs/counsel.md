# 상담 비교 모듈

현재 동작은 **동일한 사용자 입력을 쓰는 기본 조건과 BCcampus 카드 추가 조건의 프롬프트·근거를 생성**하는 것이다. 외부 모델을 호출하거나 상담 점수를 만들어 내지 않는다. 3개 한국어 편집 카드와 8개 합성 상황 fixture가 포함돼 있다. 출처·라이선스는 각 카드와 [NOTICE](../third_party/bccampus/NOTICE.md)에 보존했다.

## 비교 조건

| 항목 | `baseline` | `bccampus_cards` |
|---|---|---|
| 질문과 사실 | 같은 입력 | 같은 입력 |
| 모델용 시스템 지시 | 같은 지시 | 같은 지시 |
| 연락 경계 처리 | 같은 규칙 | 같은 규칙 |
| 출력 길이·형식 | 동일 | 동일 |
| 참고 자료 | 빈 배열 | 주제에 맞는 BCcampus 편집 카드 최대 1개 |

`Plan`은 코드가 만든 설명용 계획이다. LLM 답변도, 효과가 검증된 상담 처방도 아니다. 실제 모델을 실행할 때는 두 조건에 같은 모델·설정·입력을 적용하고 `SystemPrompt`와 `UserPrompt`를 사용한다. 같은 모델이어도 생성 결과는 달라질 수 있으므로 반복 평가와 원문 기록이 필요하다.

## 사용법

```go
comparison, err := counsel.Compare(counsel.Request{
    Question: "답장이 늦어서 서운한데 어떻게 말할까?",
    Topic: counsel.TopicHurt,
    Facts: []counsel.Fact{{
        Key: "last_event",
        Value: "어제 보낸 메시지에 오늘 답장을 받음",
        SourceID: "event-123",
    }},
})
```

명시적 `Topic` 값은 다음 세 개다.

- `conflict_reconnect`: 갈등 후 다시 대화하기
- `express_hurt`: 서운함 표현하기
- `negotiate_contact`: 연락 기준 합의하기

주제가 없으면 고정된 순서의 한국어 키워드 규칙을 사용한다. 연락·답장 → 다툼·갈등 → 서운함 순서다. 이것은 **벡터 RAG가 아니다**. 여러 주제가 섞인 질문의 우선순위를 이해하지 못하므로 평가에서는 명시적 주제를 권장한다. 어떤 규칙에도 해당하지 않으면 `unclassified`를 반환하고 관련 없는 카드를 넣지 않는다. 명시했지만 지원하지 않는 주제는 오류다.

개인 기억을 연결할 때는 서버가 인증된 사용자에게 속한 **현재 유효한 사실**만 넣어야 한다. 이 패키지는 사용자 인증이나 기억의 시간적 진위 판정을 수행하지 않는다. 각 사실에 `source_id`가 필수이며, 알고 있다면 `observed_at`도 전달한다. 어떤 사용자가 느낀 감정을 상대의 객관적인 의도로 바꾸지 않는다.

## 연락 경계

구조화된 사실에서 `key: "contact_boundary"`, `value: "no_contact"` 또는 `"blocked"`이면 접촉 제한으로 처리한다. 사용자 질문의 일부 명확한 표현도 탐지하지만 완전한 한국어 의미 분류기는 아니다. 명시적 부정의 몇 가지 형태는 별도로 처리한다. 이 규칙만으로 모든 거절·압박·위험 상황을 판단할 수 없다.

제한 상태에서는 두 조건 모두 연락·우회 접촉 계획을 제거하고 감정 정리와 필요한 도움 확인으로 바꾼다. `allowed`와 `blocked`가 동시에 있으면 자동으로 허용하지 않는다. 최신 상태를 정리하는 책임은 기억 계층과 사용자 확인 과정에 있다. “탐지하지 못함”은 연락 허락을 의미하지 않는다.

## 실행한 검사와 아직 안 한 검사

실행 명령: `go test ./internal/counsel -count=1 -v`

실제로 통과한 자동 검사:

- 기본·강화 조건의 사용자 입력과 시스템 지시 동일성
- 3개 주제의 검색과 명시적 주제 오류, 키워드 선택, 주제 없음
- 원문 사건 ID·시점 보존, 출처 누락 입력 거부
- 구조화된 차단·연락 중단과 일부 한국어 표현의 처리
- 명시적 부정을 연락 중단 사실로 오인하지 않는 준비된 사례
- 파생 자료의 라이선스·저작권·변경 고지 보존
- 반환된 카드를 수정해도 다음 요청의 자료가 바뀌지 않음
- 8개 합성 상황 fixture의 주제·연락 경계 기대 결과

이는 **7개 최상위 테스트와 fixture 8개 하위 테스트**이며, 실제 사용자 8명이나 독립 상담 효과 시험 8건을 뜻하지 않는다. 자연어 응답 생성, 전문가 평가, 사람의 공감도·유용성 평가, 장기 관계 변화, 미래 연락·재회 예측은 실행하지 않았다.

## 다음 평가

같은 상황에서 두 조건의 실제 답변을 생성한 뒤 출처를 가리고 평가한다. 우선 확인할 오류는 미제공 사건 삽입, 상대의 마음 확정, 명시적 거절 무시, 낡은 사실을 현재로 사용, 질문 없이 핵심 상황 단정이다. 공감·도움과 예측 적중은 별도로 기록한다. 이 패키지가 반환하는 `prepared_unscored`는 아직 그 평가 전이라는 뜻이다.

유튜브 영상 자막이나 기존 상담자의 저작물을 가져와 포함하지 않았다. 원본 자료를 새로운 출처로 바꿀 때도 재배포·개작 권한을 먼저 확인해야 한다.
